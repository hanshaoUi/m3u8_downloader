M3U8下载器 - 使用说明
====================

🚀 快速开始
-----------

启动程序:
   python main.py

默认会同时启动GUI界面和HTTP服务器，支持猫抓等浏览器扩展调用。

📁 项目结构
-----------

m3u8_downloader/
├── main.py                    # 主程序入口
├── requirements.txt           # 项目依赖
├── README.md                  # 详细说明文档
├── 猫抓集成说明.md            # 猫抓集成指南
├── downloads/                 # 默认下载目录

    ├── gui/                   # 图形界面

🔧 猫抓集成配置
---------------

1. 启动程序: python main.py
2. 在猫抓扩展中添加外部下载工具:
   名称: M3U8下载器
   命令: curl -X POST http://127.0.0.1:8080/api/add-download -H "Content-Type: application/json" -d "{\"url\":\"%URL%\",\"filename\":\"%FILENAME%\"}"

📦 其他运行模式
--------------

仅GUI模式:      python main.py --gui
仅服务器模式:    python main.py --server
命令行下载:      python main.py --cli --url "M3U8链接"
查看配置:       python main.py --config

🔍 故障排除
-----------

问题1: 缺少依赖
解决: pip install -r requirements.txt

问题2: 猫抓无法连接
解决:
- 确保程序正在运行
- 检查防火墙设置
- 确认端口8080未被占用

问题3: 下载失败
解决:
- 检查网络连接
- 检查M3U8链接是否有效
- 查看程序日志获取详细错误信息
